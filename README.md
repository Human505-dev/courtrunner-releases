# CourtRunner releases

Public update feed for the CourtRunner desktop app. Installers and Velopack packages are published here automatically by CI; the app updates itself from these releases.

## Download

**[Download CourtRunner](https://github.com/Human505-dev/courtrunner-releases/releases/latest/download/CourtRunner-win-Setup.exe)** (Windows, `CourtRunner-win-Setup.exe`)

This link always points at the latest release — bookmark it, don't link to a specific version's asset. Run the installer and CourtRunner keeps itself up to date automatically after that; no need to re-download for future versions.

Everything else on the [Releases](https://github.com/Human505-dev/courtrunner-releases/releases) page (`.nupkg` files, `RELEASES`, `assets.win.json`, `releases.win.json`) is an internal Velopack update artifact, not meant to be downloaded directly. The `Portable.zip` is a self-contained copy for advanced use — it does **not** self-update; use the installer above unless you specifically need portable mode.
